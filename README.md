# Salary Prediction App 🚀

An interactive web application built with **Streamlit** and **Scikit-Learn** that predicts salaries based on demographic and job parameters.

## Features
- Interactive input parameters via Streamlit.
- Data encoding using `LabelEncoder`.
- Linear Regression model for prediction.

## How to Run Locally
1. Clone this repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run Streamlit: `streamlit run Main_app.py`
